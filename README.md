A one-line roast of the smart fridge for the make.fun bounty
"Roast the Smart Fridge: One Line, Best Laugh Wins".

## The entry

> "My smart fridge photographs my leftovers every time I close the door — the only paparazzo in the house, yet it can't name one meal in there."

140 characters, one line. The joke: the fridge's interior camera
photographs your food like a celebrity stalker, yet it cannot identify a
single meal it just photographed — surveillance without comprehension.

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), after checking it is non-blank, a single
line, and 1–160 characters.
